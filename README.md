# Laiba Ausaf | Personal Portfolio Website

## About the Project

This is my personal portfolio website, developed to showcase my academic background, technical skills, projects, experience, and achievements as a Computer Science undergraduate.

The website provides an overview of my interests in Artificial Intelligence, software development, and problem-solving.

## Technologies Used

- **HTML5:** Provides the structure and content of the website.
- **CSS3:** Handles styling, layouts, animations, colors, and responsive design.
- **JavaScript:** Adds interactive features and dynamic functionality.

## Website Sections

The portfolio includes the following sections:

- **Home:** Introduction and personal profile.
- **About Me:** Background, interests, and professional goals.
- **Education:** Academic background and relevant coursework.
- **Projects:** Highlights of my academic and personal projects.
- **Skills:** Programming languages, AI technologies, web development, and database skills.
- **Experience:** AI internship and fellowship experience.
- **Activities & Achievements:** Academic and extracurricular accomplishments.
- **Contact:** Contact form for visitors.

## Key Features

- Modern dark-themed portfolio design.
- Responsive layout for different screen sizes.
- Interactive navigation menu.
- Dark and light theme toggle.
- Smooth scrolling navigation.
- Scroll progress indicator.
- Back-to-top button.
- Animated section reveals.
- Interactive project cards.
- Contact form with basic client-side validation.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code or any code editor.
3. Open `lab1.html` in your web browser.
4. Explore the different sections and interactive features of the portfolio.
